# 第一章　總則

**第 1 條**　本章程依據《臺北市數位實驗高級中等學校學生自治實施辦法》訂定之，定名為「臺北市數位實驗高級中等學校第五屆學生會組織章程」（以下簡稱本章程）。

**第 2 條**　學生會為全體在學學生之自治組織，以維護學生權益、促進校園民主、豐富校園生活為宗旨。

:::info
📌 本章程經學生代表大會決議通過後施行，修正時亦同。
:::

# 第二章　組織架構

## 第 3 條　組織單位

學生會設下列各單位：

| 單位 | 職掌 | 備考 |
| ---- | ---- | ---- |
| 會長、副會長 | 綜理會務、對外代表學生會 | 由全校學生直選產生 |
| 行政部 | 文書、檔案、會議記錄管理 | — |
| 活動部 | 校內大型活動之策劃與執行 | 含社團聯合活動 |
| 權益部 | 學生意見蒐集、校務建言 | 定期召開權益座談會 |
| 公關部 | 對外聯繫、社群媒體經營 | — |
| 財務部 | 預算編列、經費稽核 | 受學生代表大會監督 |

## 第 4 條　幹事會議

學生會每兩週召開幹事會議一次，由會長主持；必要時得召開臨時會議。

# 第三章　選舉與任期

**第 5 條**　會長、副會長任期一學年，連選得連任一次。

**第 6 條**　選舉應於每學年第二學期五月前完成，採網路投票方式辦理，並由選舉委員會監督。

# 第四章　附則

**第 7 條**　本章程未規定事項，依其他相關法規辦理。

**第 8 條**　本章程經學生代表大會通過後公布施行。
