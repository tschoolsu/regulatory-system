## 一、總說明

為維護校園生活品質與互相尊重之風氣，凡本校學生均應遵守本規範 :smile:

> [!IMPORTANT]
> 本規範之解釋與裁量的最終權責單位為 **學務處**，學生會僅提供申訴協助窗口。

## 二、儀容重點

1. 到校應著整齊清潔之服裝，校服樣式依學校公告為準
2. 頭髮應保持整潔，不得影響他人視線或安全
3. 配飾以不妨礙課程活動與安全為原則

### 每日自我檢查清單

- [x] 識別證已配掛完成
- [x] 校服無明顯污損
- [ ] 實驗課日：著包鞋
- [ ] 體育課日：攜帶運動服裝

## 三、公共空間行為

在校園公共空間應注意下列事項[^1]：

| 空間 | 應遵守事項 | 常見錯誤示例 |
| ---- | ---------- | ------------ |
| 走廊樓梯 | 靠右行走、不奔跑推擠 | 三併排聊天阻礙通行 |
| 圖書館 | 保持安靜、手機調靜音 | 外放影片聲音 |
| 午餐時間 | 依序排隊、餐後回收餐具 | 佔用他人座位 |

[^1]: 本表格由第五屆學生會權益部彙整同學常見疑問後製作。

## 四、違規處理

初次違反者以 **輔導提醒** 為原則；經提醒仍未改善者，依《獎勵實施要點》及學校相關規定處理。

:::spoiler 申訴管道怎麼走？
若對處理結果有異議，可於 **收到通知起 5 日內** 向學生會權益部提出申訴，我們將協助你與學務處進行溝通協調。申訴不影響你原本的權益！
:::

:::warning
任何形式的肢體衝突、言語霸凌，一律送交學務處依校規從嚴處理，不接受以「開玩笑」為由抗辯。
:::
